# 通达信本地前复权实施方案

> **状态**：已实施（2026-05）  
> **依赖**：`INSTOCK_TDX_DIR` 含 `vipdoc`（raw）与 `T0002/hq_cache/gbbq`；`pytdx` 解析 gbbq

## 表结构

| 表 | 用途 |
|----|------|
| `cn_stock_daily_bar` | **仅 raw**（多源 merge） |
| `cn_stock_daily_bar_qfq` | **前复权派生** |
| `cn_stock_corporate_action` | gbbq 除权事件 |
| `cn_stock_adj_factor` | 日频 qfq_factor |
| `cn_stock_qfq_watermark` | 派生水位 |

## 作业

| job_id | 说明 |
|--------|------|
| `ingest_tdx_gbbq_job` | gbbq → 事件表 |
| `derive_qfq_from_tdx_job` | raw + 事件 → qfq 表（`--mode full\|incremental`） |
| `sync_tdx_local_pipeline_job` | 一键 universe → raw → gbbq → qfq |

## 触发

- `sync_bars_mootdx_local_job` 成功后：`INSTOCK_AUTO_DERIVE_QFQ=1`（默认）自动 **incremental** 派生。
- **qfq 表为空**：不自动全量，请手动 `derive_qfq_from_tdx_job --mode full`。
- gbbq mtime 变化：自动 ingest + **full** 派生。

## 验收

```bash
python scripts/verify_tdx_qfq.py --code 600000 --from-date 20240101
python scripts/verify_tdx_qfq.py --code 600000 --l2   # 可选，需网络
```

## 算法

- gbbq 解析：`pytdx.reader.GbbqReader`
- 前复权：对齐 mootdx `baoli_qfq`（除权日前历史 OHLC 按比例调整）
- 因子链：最新交易日 `qfq_factor=1`；`close_qfq == close_raw`（最新日）

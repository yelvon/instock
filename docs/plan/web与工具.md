# Web 与工具规划

面向：提升本地维护效率；可选对外暴露时的安全。

## 1. 数据字典与 schema 文档

**需求**

- 表级说明：业务含义、更新频率、负责 job、上游依赖。
- 字段级说明：类型、枚举、主键/索引。

**验收建议**

- 与 `scripts/gen_database_schema_doc.py` 输出联动：CI 或手动命令可生成/更新文档。

---

## 2. 作业与同步面板增强（可选）

**需求**

- 在现有同步 API/页面基础上扩展：展示编排 run、各子步骤状态、最近错误摘要。
- 支持手动触发单次子 job（需权限控制，见下文）。

**验收建议**

- 本地浏览器可查看最近一次全量跑批的完整时间线与状态。

---

## 3. 回测任务提交与结果浏览（可选）

**需求**

- Web 或 CLI 提交回测：选择策略、参数、日期区间；异步执行时展示队列位置与完成通知。
- 结果页：权益曲线、关键指标、成交明细下载（CSV）。

**验收建议**

- 长回测不阻塞 Tornado 主线程（独立进程/worker 或子进程）。

---

## 4. 安全与访问控制（可选）

**需求**

- 若服务监听非 localhost：Basic Auth 或反向代理层鉴权。
- 管理类接口（触发全量、删库级操作）默认关闭或二次确认。

**验收建议**

- 未登录用户无法触发危险操作；默认安装仅本机可访问。

---

## 5. 开发者工具

**需求**

- Makefile 或 `invoke`/`just` 等统一常用命令：`lint`、`test`、`gen-doc`、`run-job-dry`。

**验收建议**

- 新贡献者按一页文档即可完成环境搭建与跑一次 dry-run。

---

## 6. 静态资源与前端依赖（维护性）

**需求**

- 记录前端库版本来源（如 Tabulator、Bokeh）；重大升级前在 `docs/plan` 或 changelog 中登记兼容性检查项。

**验收建议**

- 升级后关键报表页手动检查清单可勾选完成。

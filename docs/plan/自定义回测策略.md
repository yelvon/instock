# 自定义回测策略（Backtrader 式）

架构说明见 [回测Backtrader式架构.md](./回测Backtrader式架构.md)。  
**策略目录与维护流程**见 [回测策略目录.md](./回测策略目录.md)。

## 1. 新增内置策略（推荐团队维护）

在 `instock/core/backtest/strategies/` 新建模块，继承 `Strategy`：

```python
from instock.core.backtest.strategy import Strategy

class MyStrategy(Strategy):
    strategy_id = "my_strategy"
    default_params = {"threshold": 10}

    def next(self, date: str) -> None:
        ...
```

在 [`builtins_catalog.py`](../../instock/core/backtest/strategies/builtins_catalog.py) 的 `_technical_catalog()` 中登记：

```python
from instock.core.backtest.strategy_meta import ParamDef

StrategyCatalogEntry(
    strategy_id=MyStrategy.strategy_id,
    strategy_cls=MyStrategy,
    title="我的策略",
    description="...",
    category="technical",
    param_defs=[ParamDef("threshold", "阈值", "int", 10, min=1, max=100)],
)
```

## 2. 插件目录

路径：`instock/core/backtest/strategies/plugins/`

- 新建 `my_strategy.py`，末尾调用 `register(..., category="plugin", param_defs=[...])`
- 可选环境变量：`INSTOCK_STRATEGY_PLUGINS=my_package.my_mod`（逗号分隔）
- 加载失败写日志；`INSTOCK_STRATEGY_PLUGINS_STRICT=1` 时启动失败

策略内 **禁止** import Web、写数据库。

## 3. Web / API

- 列出策略：`GET /instock/api/backtest/strategies`（含 `category`、`params` 中文 label）
- 创建回测：`POST /instock/api/backtest/runs`

```json
"strategy": { "id": "moving_average_cross", "params": { "fast": 5, "slow": 20 } }
```

服务端会校验参数类型与范围（如 `fast < slow`）。

## 4. 与选股 job 区别

| 方式 | 用途 |
|------|------|
| `strategy_data_daily_job` + `core/strategy` | 每日筛股写入 MySQL |
| `screening_*` 回测策略 | 用历史 K 线在回测里调用同一 `check_*` |

# 自定义回测策略（Backtrader 式）

架构说明见 [回测Backtrader式架构.md](./回测Backtrader式架构.md)。

## 1. 新增内置策略

在 `instock/core/backtest/strategies/` 新建模块，继承 `Strategy`：

```python
from instock.core.backtest.strategy import Strategy
from instock.core.backtest.registry import register

class MyStrategy(Strategy):
    strategy_id = "my_strategy"
    default_params = {"threshold": 10}

    def next(self, date: str) -> None:
        ...

register(MyStrategy.strategy_id, MyStrategy, title="我的策略", description="...")
```

在 `registry.py` 的 `_register_builtins()` 中 import 并 register，或放在 `strategies/plugins/` 由扫描加载。

## 2. 插件目录

路径：`instock/core/backtest/strategies/plugins/`

- 新建 `my_strategy.py`，末尾调用 `register(...)`
- 可选环境变量：`INSTOCK_STRATEGY_PLUGINS=my_package.my_mod`（额外模块路径，逗号分隔）

策略内 **禁止** import Web、写数据库。

## 3. Web / API

- 列出策略：`GET /instock/api/backtest/strategies`
- 创建回测：`POST /instock/api/backtest/runs`，body 中：

```json
"strategy": { "id": "moving_average_cross", "params": { "fast": 5, "slow": 20 } }
```

## 4. 与选股 job 区别

| 方式 | 用途 |
|------|------|
| `strategy_data_daily_job` + `core/strategy` | 每日筛股写入 MySQL |
| `screening_bridge` 回测策略 | 用历史 K 线在回测里调用同一 `check_*` |

# InStock 长期本地维护与自定义回测 — 规划索引

本目录存放「可长期本地维护股票数据 + 自定义回测策略」相关的分层需求与技术规划，便于按层评审、排期与编码。

## 目标画像

- **数据**：多年数据可增量更新；断档可发现、可补拉；schema 可版本化迁移；环境可一键恢复。
- **回测**：策略、数据、参数、版本可复现；成本与交易规则可配置；结果可对比、可导出。
- **维护**：任务可观测；日志可定位；敏感配置不进仓库。

## 文档结构

| 文件 | 层级说明 |
|------|----------|
| [data.md](./data.md) | 数据管线：增量、质量、补数、源抽象、元数据、存储、备份 |
| [backtest.md](./backtest.md) | 回测引擎：模型、成本、约束、资金、复现性、绩效、过拟合控制 |
| [strategy.md](./strategy.md) | 自定义策略：接口契约、插件化、参数版本、测试、因子库 |
| [ops-scheduling.md](./ops-scheduling.md) | 任务调度与可观测：编排、依赖、重试、幂等、面板、配置分层 |
| [web-tools.md](./web-tools.md) | Web 与工具：数据字典、回测任务、权限（可选） |
| [roadmap.md](./roadmap.md) | 分阶段路线图与优先级 |
| [repo-alignment.md](./repo-alignment.md) | 与当前仓库结构的衔接与注意事项 |

阅读顺序建议：`README.md`（本页）→ `roadmap.md` → 按当前迭代选择对应层级文件。

## 维护约定

- 各文件可独立增删「需求条目 / 验收标准 / 技术备注」，重大方向变更时在 `roadmap.md` 同步阶段与优先级。
- 实现某一需求后，可在对应文件条目下增加「实现 PR / 提交 / 日期」短链（可选）。

# InStock 长期本地维护与自定义回测 — 规划索引

本目录（`docs/plan/`）统一存放需求规划、实施方案、验收清单与路线图，便于按层评审、排期与编码。

## 目标画像

- **数据**：多年数据可增量更新；断档可发现、可补拉；schema 可版本化迁移；环境可一键恢复。
- **回测**：策略、数据、参数、版本可复现；成本与交易规则可配置；结果可对比、可导出。
- **维护**：任务可观测；日志可定位；敏感配置不进仓库。

## 维护约定

- 新规划/方案均以 `docs/plan/<主题>.md` 命名（中文主题名即可），在本索引「文档结构」中登记一行。
- 需求级口径变更写在对应需求文档（如 `回测.md`）；模块划分、PR 阶段、任务勾选写在实施方案文档。
- 重大方向变更时在 [路线图.md](./路线图.md) 同步阶段与优先级。
- 实现完成后可在对应文件增加「实现 PR / 日期」短链（可选）；并更新 [AGENTS.md](../../AGENTS.md) §9。

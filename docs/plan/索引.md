# InStock 长期本地维护与自定义回测 — 规划索引

本目录存放「可长期本地维护股票数据 + 自定义回测策略」相关的分层需求与技术规划，便于按层评审、排期与编码。

## 目标画像

- **数据**：多年数据可增量更新；断档可发现、可补拉；schema 可版本化迁移；环境可一键恢复。
- **回测**：策略、数据、参数、版本可复现；成本与交易规则可配置；结果可对比、可导出。
- **维护**：任务可观测；日志可定位；敏感配置不进仓库。
